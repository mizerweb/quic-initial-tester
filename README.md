# quic-initial-tester
Отправляет quic_initial дамп вида '.bin' на необходимый домен, для проверки работоспособности ресурса на протоколе QUIC!

> ⚠️ **Обратите внимание:** проект находится на этапе разработки! Все предложения по улучшению или сообщения о багах отправляйте в **Issues**.
